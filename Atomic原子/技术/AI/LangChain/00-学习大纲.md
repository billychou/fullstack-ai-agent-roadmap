# LangChain 深度学习大纲

> 目标：系统掌握 LangChain 生态（LangChain / LangGraph / LangSmith），能独立开发生产级 LLM 应用与 Agent。
> 版本基线：**LangChain 1.x**（2025-10 发布 1.0，2026 年当前 1.3.x）—— 网上大量 2023 年老教程已过时，**一律以官方文档 docs.langchain.com 为准**。

## 0. 生态全景（先搞清楚三件套）

| 组件 | 定位 | 开源 | 一句话 |
|---|---|---|---|
| **LangChain** | 高层 Agent 框架：模型抽象、工具、Prompt、标准 Agent 循环 | ✅ MIT | 最快上手，`create_agent` 十行搞定一个 Agent |
| **LangGraph** | 底层编排运行时：状态图、Checkpoint、持久化、Human-in-the-loop | ✅ MIT | 需要自定义流程/长任务/生产级时下沉到这一层 |
| **LangSmith** | 可观测 + 评测 + 部署平台 | ❌ 商业 | 上线必用：Trace 追踪、数据集评测、LangServe 部署 |

**核心认知（1.0 重构后的新世界观）：**
- 旧版「Chains + Memory 类 + 六种 Agent 模式」已整体迁入 `langchain-classic`，**不要再学**。
- 1.x 核心只有一个原语：`create_agent`，底层跑在 LangGraph 上。
- LangGraph 不是 LangChain 的竞品，**是它的运行时**。
- 简单流水线也可能不需要框架 —— 直接调 LLM API + 向量库客户端即可（框架不背锅）。

## 1. 学习路径（8 个阶段）

### 阶段一：环境与第一个 Agent（0.5 天）
- [ ] 安装：`pip install langchain langchain-openai langgraph`
- [ ] 跑通 `create_agent` 最小示例（模型 + 1 个工具 + system_prompt）
- [ ] 理解 `agent.invoke({"messages": [...]})` 的消息结构
- 📄 → [[01-生态全景与1.0重构]] / [[02-模型与消息]]

### 阶段二：模型与提示词（1 天）
- [ ] Chat Models 统一接口：OpenAI / Anthropic / Ollama 一行切换
- [ ] 消息类型：System / Human / AI / Tool；`bind_tools`
- [ ] Prompt Templates：`ChatPromptTemplate`、变量注入、`from_messages`
- [ ] 结构化输出：`with_structured_output`（Pydantic schema）
- 📄 → [[02-模型与消息]] / [[03-提示词与结构化输出]]

### 阶段三：工具与 Agent（1~2 天）
- [ ] 用 `@tool` 装饰器把普通函数变成工具（名字/描述/参数类型）
- [ ] `create_agent` 全参数：model、tools、system_prompt、state、middleware
- [ ] Agent 循环原理：ReAct（Reason + Act）——模型决定调哪个工具→观察结果→继续
- [ ] 多工具场景与工具选择策略
- 📄 → [[04-工具与Agent]]

### 阶段四：RAG 检索增强生成（2~3 天）
- [ ] 完整链路：加载 → 切分 → 向量化 → 存储 → 检索 → 生成
- [ ] Document Loaders（PDF / Web / 数据库等）
- [ ] Text Splitters（`RecursiveCharacterTextSplitter` 等）
- [ ] Embeddings + Vector Store（Chroma / FAISS / pgvector）
- [ ] Retriever 进阶：MMR、多查询、上下文压缩、Rerank
- [ ] 手写一个知识库问答机器人
- 📄 → [[05-RAG检索增强生成]]

### 阶段五：LangGraph 运行时（2~3 天）
- [ ] StateGraph：节点 / 边 / 条件分支 / 循环
- [ ] Checkpointer：状态持久化、断点续跑、time-travel 调试
- [ ] Human-in-the-loop：`interrupt()` 暂停等人工审批
- [ ] 多 Agent：Orchestrator-Worker / Supervisor / Swarm 模式
- [ ] 与 `create_agent` 的关系：自定义流程时下沉到这层
- 📄 → [[06-LangGraph运行时]]（衔接 [[W03-LangGraph入门|全栈学习路线 LangGraph 入门]]）

### 阶段六：工程化与可观测（1~2 天）
- [ ] 流式输出：`stream` / `astream_events`
- [ ] LangSmith：Trace 追踪、数据集评测、回归测试
- [ ] LangServe 部署：把 Agent 变成 REST API
- [ ] 成本与延迟优化：缓存、批处理、模型路由
- [ ] 安全：提示注入防护、工具权限控制
- 📄 → [[07-工程化与LangSmith]]

### 阶段七：实战项目（1~2 周）
- [ ] **项目 A**：企业知识库问答（RAG + 引用溯源 + 流式输出）
- [ ] **项目 B**：多工具个人助理（搜索 + 日历 + 邮件）
- [ ] **项目 C**：客服工单多 Agent（分工协作 + 人工审批 HITL）
- [ ] **项目 D**：结合 MCP 生态的 Agent
- 📄 → [[08-实战项目]]

### 阶段八：源码阅读（选学）
- [ ] 读 `create_agent` 源码，理解它如何构建 LangGraph 图
- [ ] 读 `langchain-core` 的消息/runnable 协议
- 参考：[[W11-LangGraph源码导读|全栈学习路线 W11-LangGraph 源码导读]]

## 3. 避坑清单（2026 现状）

1. ⚠️ 老教程（2023~2024）讲的 `LLMChain`、`ConversationBufferMemory`、`initialize_agent` 全部废弃，看到直接跳过。
2. ⚠️ 版本不同 API 差异大：先 `pip show langchain` 确认 1.x，再查文档。
3. ⚠️ LangGraph ≠ LangChain 竞品，别浪费时间对比，它们是上下层关系。
4. ⚠️ 简单场景别硬上框架：一个工具 + 一个模型，直接写 Python 循环更清晰。
5. ✅ 遇坑先查官方文档和 GitHub issue，Reddit 上的旧答案大概率已失效。
