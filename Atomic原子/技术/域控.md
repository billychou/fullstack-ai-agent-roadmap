在 Windows Active Directory (AD) 中限制或控制用户的访问时间（允许登录的时间段），是通过设置用户的 **`logonHours`** 属性来实现的。


`logonHours` 是一个包含 **21 个字节（168 个 Bit）** 的二进制/字节串字段：



- 对应一周 **7 天 × 24 小时 = 168 小时**。
- 每个 Bit 代表 1 个小时：`1` 表示允许登录，`0` 表示禁止登录。
- **时区说明**：AD 数据库内部存储的 `logonHours` 时间统一使用 **UTC 时间**（格林威治标准时间）。因此在 Python 中配置时，必须**将本地时间转换/偏移为 UTC 时间**。
    
      
    

## 示例代码：设置用户登录时间段

下面的代码示例演示了如何通过 `ldap3` 将目标用户的登录时间限制为：

👉 **周一至周五，每天上午 08:00 到 18:00（以 UTC+8 中国标准时间为例）**

  

Python

```
from ldap3 import Server, Connection, ALL, NTLM, MODIFY_REPLACE

# ==================== 1. 配置 AD 连接 ====================
LDAP_SERVER = 'ldap://your-dc.yourdomain.com'
DOMAIN = 'YOURDOMAIN'
USERNAME = 'admin_user'
PASSWORD = 'admin_password'
BASE_DN = 'DC=yourdomain,DC=com'

server = Server(LDAP_SERVER, get_info=ALL)
conn = Connection(
    server, 
    user=f"{DOMAIN}\\{USERNAME}", 
    password=PASSWORD, 
    authentication=NTLM, 
    auto_bind=True
)

TARGET_SAM_ACCOUNT = "zhangsan"

# ==================== 2. 构造 logonHours 掩码 ====================
def generate_logon_hours(allowed_slots, timezone_offset=8):
    """
    生成 21 字节的 logonHours bytearray
    :param allowed_slots: 字典，定义本地时间允许的登录时段。0=周日, 1=周一, ..., 6=周六
    :param timezone_offset: 本地时区相对于 UTC 的偏移量 (北京时间为 +8)
    """
    # 建立 168 个小时的 bit 数组，默认全部禁止 (0)
    # 索引 0 代表 UTC 周日 00:00-01:00
    grid = [0] * 168
    
    for local_day, hours in allowed_slots.items():
        for local_hour in hours:
            # 1. 计算本地时间的总小时索引 (0 - 167)
            local_index = local_day * 24 + local_hour
            
            # 2. 转换为 UTC 时间的索引
            utc_index = (local_index - timezone_offset) % 168
            
            # 3. 设置该时段允许登录
            grid[utc_index] = 1

    # 将 168 个 bits 转换为 21 个字节 (每个字节 8 bits，低位在前)
    logon_hours_bytes = bytearray(21)
    for i in range(168):
        byte_index = i // 8
        bit_index = i % 8
        if grid[i] == 1:
            logon_hours_bytes[byte_index] |= (1 << bit_index)
            
    return bytes(logon_hours_bytes)

# 定义本地允许登录的时间 (假设本地为 UTC+8)
# 0=周日, 1=周一, 2=周二, 3=周三, 4=周四, 5=周五, 6=周六
work_hours = list(range(8, 18))  # 08:00 到 17:59 (即 8..17)

allowed_schedule = {
    1: work_hours,  # 周一 8:00-18:00
    2: work_hours,  # 周二 8:00-18:00
    3: work_hours,  # 周三 8:00-18:00
    4: work_hours,  # 周四 8:00-18:00
    5: work_hours,  # 周五 8:00-18:00
    # 周六(6)、周日(0) 未定义，表示全天禁止登录
}

# 生成适用于 UTC+8 的 logonHours 字节流
logon_hours_data = generate_logon_hours(allowed_schedule, timezone_offset=8)


# ==================== 3. 查询并更新用户属性 ====================
conn.search(
    search_base=BASE_DN,
    search_filter=f"(&(objectClass=user)(sAMAccountName={TARGET_SAM_ACCOUNT}))",
    attributes=['distinguishedName', 'logonHours']
)

if conn.entries:
    user_dn = conn.entries[0].entry_dn
    
    # 更新 logonHours 属性
    response = conn.modify(
        dn=user_dn,
        changes={'logonHours': [(MODIFY_REPLACE, [logon_hours_data])]}
    )
    
    if response:
        print(f"[+] 成功更新用户 {TARGET_SAM_ACCOUNT} 的访问时间限制！")
    else:
        print(f"[!] 更新失败: {conn.result}")

conn.unbind()
```

## 恢复默认（取消时间限制）

如果要取消该用户的登录时间限制（即允许 **7×24 小时** 任意时间登录），只需将 21 个字节全部设为 `0xFF`（即 168 个 Bit 全部为 1）：

  
Python

```
# 21 个 0xFF 字节代表允许所有时间段登录
unrestricted_logon_hours = b'\xff' * 21

conn.modify(
    dn=user_dn,
    changes={'logonHours': [(MODIFY_REPLACE, [unrestricted_logon_hours])]}
)
```

## 核心要点解析

1. **字节顺序与 Bit 映射**：
    
    AD 中的 `logonHours` 按字节存储，字节内部使用的是**小端序（Little-Endian Bit Array）**。例如，第 1 个字节控制 UTC 周日 00:00 至 07:59 的 8 个小时，Bit 0 对应 00:00-01:00，Bit 7 对应 07:00-08:00。

      
    
2. **强制断开已登录连接**：
    
    配置 `logonHours` 默认只会阻止用户在禁止的时间段**发起新的登录**。如果希望时间一到自动将已登录的用户踢下线，需要在**域组策略 (GPO)** 中开启：
    
    `计算机配置` -> `Windows 设置` -> `安全设置` -> `本地策略` -> `安全选项` -> **`网络安全: 在登录时间过期时强制注销`**。
