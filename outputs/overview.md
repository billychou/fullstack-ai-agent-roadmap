# 个人工作台 — 搭建完成

## 模块（4 个）
1. **任务管理** — P0/P1/P2 优先级、截止日期、分类、完成率进度环、逾期统计
2. **学习进度** — 全栈 AI 学习路线/LangChain 8 阶段进度条、每日打卡、连续天数
3. **健康管理** — 体重记录 + SVG 折线图、目标 2026-10-01 前 ≤60KG、进度卡、运动打卡
4. **灵感笔记** — 金句速记、标签分类（预置 3 条来自《AI感悟》笔记）

## 关键特性（对齐专家铁律）
- **「今天要处理」置顶**：逾期（标红 + 一键完成）/ 今天到期 / 近 3 天到期自动列出，未打卡提示
- **示例数据**：4 任务（含 1 条逾期）+ 8 学习阶段 + 5 条体重 + 3 条灵感，附「清空示例」按钮
- **数据安全**：localStorage（key 前缀 `wb_personal_`）+ 首屏「备份/导入」按钮 + 30 条备份提示 + 清空二次确认
- **双端适配**：桌面顶部 Tab / 移动端底部 Tab、按钮 ≥44px、输入框 16px、iPhone 安全区
- **图表/图标**：进度环、折线图、条形进度均为内联 SVG，图标为内联 SVG path，无 emoji
